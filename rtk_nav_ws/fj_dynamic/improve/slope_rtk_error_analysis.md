# 山地坡面 RTK 定点误差分析

## 1. 现象描述

- 平地测量：平均误差约 **5 cm**。
- 山上坡地测试：同一类流程下，丰疆复测误差达到 **30-50 cm**。
- 当前测量链路：
  - 目标点 `a`：在山上用 **丰疆 RTK** 录点，采用铅锤方式对准地面点。
  - 机器人定位：**司南 RTK** 安装在机器狗上。
  - 机器人行驶到有坡度的 `a` 附近后，再用丰疆复测，发现误差明显放大。

初步判断：如果平地可以稳定到 5 cm，而坡地变成 30-50 cm，主要问题不应只归因于丰疆和司南之间的固定坐标系统差。更可能是坡地引入了 **天线安装高度、机器狗俯仰/横滚姿态、铅垂投影、坡面接地点和导航控制点不一致** 等几何误差。

---

## 2. 核心结论

山地 30-50 cm 误差最可能来自以下组合：

1. **司南 RTK 天线不等于地面目标点**
   - 丰疆录点时，点 `a` 是铅垂投到地面的物理点。
   - 机器狗导航时，司南 RTK 输出的是天线相位中心附近的坐标。
   - 在平地上，如果天线、底盘参考点、喷涂点之间的外参已经标好，误差可以被控制。
   - 到坡地后，机器狗机身发生俯仰/横滚，天线的地面铅垂投影会相对底盘参考点发生明显水平偏移。

2. **导航只按二维 `E/N` 到点，没有把坡地姿态下的三维杆臂补偿进去**
   - 机器人通常使用平面坐标 `E/N` 判断是否到达目标。
   - 如果 RTK 天线离地高度为 `h`，坡面或机身俯仰角为 `theta`，仅由高度杆臂产生的水平偏移近似为：

     ```text
     horizontal_error ~= h * sin(theta)
     ```

   - 示例：

     | 天线高度 h | 俯仰/横滚角 theta | 可能水平偏移 |
     |---:|---:|---:|
     | 0.60 m | 15 deg | 15.5 cm |
     | 0.80 m | 20 deg | 27.4 cm |
     | 1.00 m | 25 deg | 42.3 cm |
     | 1.00 m | 30 deg | 50.0 cm |

   - 因此，山地出现 **30-50 cm** 与“天线高度 + 坡地姿态未补偿”的量级非常吻合。

3. **丰疆铅锤录点和机器狗实际停靠点的物理定义不同**
   - 丰疆录的是地面点 `a`。
   - 机器狗可能控制的是：
     - RTK 天线坐标到 `a`；
     - base_link 坐标到 `a`；
     - 机械臂末端或喷涂点到 `a`；
     - 或者代码中某个经过 `rtk_x_offset / arm_offset_x` 修正后的点到 `a`。
   - 平地时这些点之间可以用固定二维外参描述。
   - 坡地时如果只用 yaw 修正，不用 roll/pitch 修正，外参会随姿态变化，固定二维补偿失效。

4. **山地 GNSS 环境会进一步放大误差**
   - 山坡、树木、岩壁、建筑、车体遮挡会造成多路径和卫星几何变差。
   - 如果 RTK 状态从 fixed 变成 float，或者 correction 链路不稳定，误差可能直接到几十厘米。
   - 但如果误差方向稳定地沿上坡/下坡方向偏，优先怀疑几何杆臂；如果误差方向随机跳变，再重点怀疑 RTK 质量。

## 3. 误差来源拆解

### 3.1 坡地姿态导致天线铅垂投影偏移

假设司南 RTK 天线安装在机器狗上方，距离底盘参考点或喷涂参考点有一定高度。平地时，天线相对地面目标点的水平投影关系基本固定。

到坡地后，机器狗身体会随坡面倾斜：

```text
平地：
  天线
   |
   |
  参考点/喷涂点

坡地：
      天线
       \
        \
      参考点/喷涂点
```

这时天线在世界坐标系下的 `E/N` 不再只是参考点加一个固定 yaw 外参，而是还受 roll/pitch 影响。只要导航或误差分析没有使用完整三维姿态补偿，就会把“天线位置到了”误认为“地面点到了”。

### 3.2 铅锤录点和机器狗底盘接地点不等价

丰疆使用铅锤方式录点，本质是在定义地面点的铅垂投影坐标。这是正确做法，但它定义的是 **地面点**。

机器狗上坡到 `a` 时，需要明确到底要求哪个点对准 `a`：

| 对准对象 | 含义 | 坡地风险 |
|---|---|---|
| 司南天线相位中心 | RTK 直接输出点 | 天线在空中，不是地面点 |
| 司南天线地面铅垂投影 | 天线正下方地面点 | 受机身姿态影响 |
| base_link 地面投影 | 底盘中心落地点 | 需要标定天线到 base_link 的三维外参 |
| 喷涂末端地面点 | 最终作业点 | 还要叠加机械臂外参和姿态 |

如果丰疆复测的是地面点，而机器人导航控制的是天线坐标，两者天然会差一个与坡度相关的投影量。

### 3.3 二维外参在坡地失效

项目现有误差里，平地主要处理的是：

- 丰疆和司南之间的固定系统差；
- `rtk_x_offset`；
- 机械臂前向补偿；
- yaw 对齐残差；
- 多帧 RTK 均值。

这些方法默认“机器人基本水平”，或者至少默认外参可以用二维平面关系描述。

坡地时，真实外参应为三维：

```text
world_point = antenna_world + R(roll, pitch, yaw) * lever_arm_body
```

如果代码只用 `yaw`，忽略 `roll/pitch`，那么坡度越大、天线越高、机械臂越长，误差越大。

### 3.4 RTK 质量和多路径

山地环境下也要检查 RTK 本身：

- 是否始终为 RTK fixed；
- 卫星数是否下降；
- PDOP/HDOP 是否明显变差；
- 差分链路是否中断；
- 天线附近是否有机身、机械臂、电池、金属结构遮挡；
- 坡面附近是否有树木、岩壁、建筑导致多路径。

如果同一个点静止不动，司南或丰疆坐标会在几十厘米范围内慢慢漂移，说明 RTK 质量本身已经不满足厘米级作业。

## 4. 建议现场验证实验

### 实验 A：同一点静态对比，确认是不是 RTK 本体问题

目的：排除司南和丰疆在山地的 RTK fixed 质量问题。

步骤：

1. 在坡地选择一个清晰地面点 `a`。
2. 用丰疆铅锤测 `a`，记录 `E_fj, N_fj, Z_fj`，并记录 fixed/float 状态。
3. 不移动机器狗，让司南静止采集 30-60 秒，记录：
   - `/epsg_position`；
   - RTK 状态；
   - 卫星数；
   - roll/pitch/yaw；
   - HDOP/PDOP，如果有。
4. 观察司南静态坐标标准差。

判定：

- 静态标准差仍在 1-3 cm：RTK 本体大概率没问题。
- 静态坐标波动 10 cm 以上：先解决山地 RTK 质量、多路径、差分链路问题。
- 静态稳定但与丰疆固定差 5-10 cm：属于司南-丰疆系统差，可用公共点校正。
- 静态稳定但机器人执行后误差 30-50 cm：重点查坡地姿态杆臂和控制点定义。

### 实验 B：同一点不同朝向，验证杆臂误差

目的：判断误差是否随机器狗 yaw / pitch / roll 变化。

步骤：

1. 在坡地固定地面点 `a`。
2. 每次让机器狗尽量停在同一物理点附近，分别朝：
   - 上坡；
   - 下坡；
   - 横坡向左；
   - 横坡向右。
3. 每个朝向记录司南 `E/N/Z` 和 roll/pitch/yaw。
4. 用丰疆复测实际参考点或喷涂点。

判定：

- 如果误差方向随朝向翻转，说明主要是天线/机身杆臂外参问题。
- 如果误差始终沿坡度方向，说明主要是坡面投影或铅垂点定义问题。
- 如果误差随机，优先检查 RTK fixed 质量和多路径。

### 实验 C：量天线高度和坡度，做量级反推

现场记录：

```text
h = 司南天线相位中心到目标参考点的高度
theta_pitch = 机器狗上坡/下坡俯仰角
theta_roll = 机器狗横坡横滚角
```

估算：

```text
前后向误差 ~= h * sin(theta_pitch)
左右向误差 ~= h * sin(theta_roll)
```

如果估算值接近现场 30-50 cm，则基本可以确认是坡地姿态杆臂未补偿。

## 5. 整改建议

### 5.1 明确最终要对准的物理点

必须先定义清楚：到点时到底要求哪个点与丰疆录入的地面点 `a` 重合。

建议项目统一为：

```text
丰疆目标点 a = 最终喷涂点/作业点在地面的铅垂投影
```

这样机器人侧要做的是：用司南 RTK + IMU 姿态 + 三维外参，计算“喷涂点地面投影”的世界坐标，而不是直接用天线坐标去追目标。

### 5.2 建立三维外参模型

需要测量并固化：

- 司南 RTK 天线相位中心相对 `base_link` 的三维偏移：
  - `rtk_x_offset`
  - `rtk_y_offset`
  - `rtk_z_offset`
- 喷涂点或目标参考点相对 `base_link` 的三维偏移：
  - `tool_x_offset`
  - `tool_y_offset`
  - `tool_z_offset`

计算时使用完整姿态：

```text
target_point_world = rtk_world + R(roll, pitch, yaw) * offset_rtk_to_target_body
```

其中 `R` 不能只使用 yaw，坡地必须包含 roll/pitch。

### 5.3 坡地单独做公共点标定

平地 5 cm 标定不能直接代表山地。

建议在山地作业区域布置 6-10 个公共点：

- 覆盖上坡、下坡、横坡；
- 覆盖不同朝向；
- 每个点记录丰疆坐标、司南坐标、机器狗姿态、RTK 状态；
- 分别统计：
  - 司南-丰疆固定系统差；
  - 与坡度相关的误差；
  - 与机器狗朝向相关的误差。

如果误差能被 `h * sin(theta)` 解释，就优先做三维外参补偿；如果仍有稳定的区域性偏差，再叠加司南-丰疆坐标校正。

### 5.4 现场操作 SOP

1. 丰疆录点时必须保证杆身竖直、气泡居中，记录 RTK fixed 状态。
2. 司南作业时记录每个点到达瞬间的：
   - `E/N/Z`；
   - roll/pitch/yaw；
   - RTK fixed/float；
   - 卫星数和 HDOP/PDOP；
   - 机器人目标点、base_link、喷涂点估算坐标。
3. 坡度超过 10 deg 的点，不能再用平地二维外参直接验收。
4. 每次山地测试至少留 3 个重复点：
   - 同一点同朝向重复；
   - 同一点反向重复；
   - 同一点横坡方向重复。
5. 复测误差要同时按世界坐标和机体系坐标统计：
   - 世界 `dE/dN`；
   - 机体系 `body_x/body_y`；
   - 坡向/横坡向误差。

## 6. 优先排查清单

按优先级从高到低：

1. **确认司南天线高度 `h` 和机器狗坡地 pitch/roll**
   - 如果 `h` 在 0.8-1.0 m，坡度 20-30 deg，30-50 cm 误差完全合理。

2. **确认导航控制点**
   - 当前代码到底是在让司南天线、base_link、还是喷涂点到达丰疆目标坐标。

3. **检查代码是否只用 yaw 做外参补偿**
   - 如果只用 yaw，坡地必然存在系统性偏差。

4. **检查 RTK fixed 状态**
   - 山地如果存在 float、差分中断、多路径，先不要分析厘米级外参。

5. **检查丰疆复测对象是否一致**
   - 复测的是地面点、喷涂点、脚印点，还是天线铅垂点，必须与录点定义一致。

6. **做同一点多朝向实验**
   - 这是最快区分“姿态杆臂问题”和“RTK 本体问题”的方法。

---

## 7. 当前判断

结合“平地平均 5 cm、山地 30-50 cm”的量级，最可疑问题是：

```text
司南 RTK 安装在机器狗上方，坡地时机器狗 pitch/roll 改变，
但导航和误差补偿仍按平地二维外参处理，
导致天线坐标、base_link 地面投影、喷涂点地面投影之间产生 30-50 cm 的水平偏移。
```

丰疆和司南之间的坐标系统差仍然存在，但它通常解释的是 **几厘米级** 误差，不足以单独解释坡地 30-50 cm。山地 RTK 多路径也可能参与放大误差，但应先用静态 fixed 质量实验排除。

下一步最关键的是：在坡地记录每个点到达瞬间的司南 `E/N/Z + roll/pitch/yaw + RTK 状态`，并用同一点多朝向实验验证误差是否随姿态和朝向变化。一旦验证成立，就需要把机器人侧补偿从二维 yaw 外参升级为包含 roll/pitch 的三维杆臂补偿。
