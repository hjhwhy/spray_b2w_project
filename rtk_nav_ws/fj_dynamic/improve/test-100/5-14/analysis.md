## 与 5-13 Top10 对比观察

- 5-13 Top10 集中在 pt30–pt38 簇状偏置区域，最大 17.6 cm。

- 体现 `cde13fa` 修正前向补偿后，原 pt30–pt38 区域系统性偏负 dN 被压下去，但出现新的偏置方向（见下方“关键差异”）。

## 关键差异（5-14 相比 5-13）

1. **前向补偿过头**：`body_x` 均值从 -1.67 cm → +3.13 cm，方向翻转、量值变大 4.8 cm。`cde13fa` 修正方向正确但补偿量明显过大；同时 body_x 标准差从 5.4 cm → 2.2 cm，说明补偿模型本身一致性更好，单纯需要回调约 3 cm。
2. **dN 系统偏置基本消除**：`dN_mean` 从 -3.34 cm → -1.71 cm，长尾误差显著减小（最大 17.6 → 15.9 cm，P95 12.9 → 10.1 cm）。
3. **横向偏置归零**：`body_y` 均值从 +1.79 cm → -0.17 cm，机械臂左右挂载位置已经标好。
4. **整体分布更紧凑**：≤8 cm 比例 75% → 89%，≤10 cm 比例 83% → 94%；但 ≤3 cm 比例 37% → 19%，因为整体偏置中心被推到 3 cm 附近——回调过补偿后可回升。
5. **间距精度提升**：相邻点间距 RMSE 3.0 → 3.57 cm 略涨，但最大值从 15.5 cm → 9.9 cm，长尾被压下去。
6. **pt77 漏测复现**：两次测试均漏 pt77。pt77 与 pt78 间距约 6 cm，远小于平均 180 cm，倾向于丰疆 RTK 录入侧的近距点合并问题。

- 当前有效复测点仍未达到“均值 ≤ 3 cm 且最大 ≤ 5 cm”的最终目标，但 5-14 相对 5-13 在 P95 / 最大值 / 长尾分布上有明显改善。
- 平均偏差为 dE=-1.8 cm、dN=-1.7 cm；机体系均值为 body_x=+3.1 cm、body_y=-0.2 cm。
- **下一步建议**：回调 `cde13fa` 引入的前向补偿约 3 cm（保留 1.5 cm 余量），目标使 body_x 回到 0；预期整体平均误差降到 4 cm 量级，≤3 cm 比例回到 40%+ 区间。
